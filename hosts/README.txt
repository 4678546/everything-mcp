hosts\ - MCP configuration snippets generated by scripts\setup.ps1

scripts\setup.ps1 rewrites the files in this directory with absolute paths for the
machine it ran on:

  claude-desktop.json   Claude Desktop / Claude Code style {"mcpServers": ...}
  cursor.json           Cursor style {"mcpServers": ...}
  gemini-cli.json       Gemini CLI style {"mcpServers": ...}
  codex.toml            Codex CLI [mcp_servers.everything] table
  dsh-snippet.yml       DeepSeek Harness cordis.patch.yml insert snippet

Copy the block for your host into that host's MCP configuration and restart the
host application.  Delete this README only if you want a clean directory.
